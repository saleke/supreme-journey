The Django Template Engine

Django’s default template engine provides an engineered mini-language to dynamically build HTML securely and cleanly. It features:

  • Blocks: Placeholders within parent layouts that child templates can selectively override using {% templatetag openblock %} block name {% templatetag closeblock %} syntax.
  • Loops: Iterative control structures written as {% templatetag openblock %} for item in list {% templatetag closeblock %} to loop through data lists sequentially.
  • If control structures: Conditional evaluations using {% templatetag openblock %} if condition {% templatetag closeblock %} to display code fragments selectively.
  • Context variables: Values dynamically passed from your Python backend into the template wrapper, printed inside double brackets like {% templatetag openvariable %} variable_name {% templatetag closevariable %}.
