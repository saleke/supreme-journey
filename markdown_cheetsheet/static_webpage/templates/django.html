Django Web Framework & History

Django is a high-level Python web framework that encourages rapid development and clean, pragmatic design. It was created in 2003 by web developers Adrian Holovaty and Simon Willison at the Lawrence Journal-World newspaper. It was publicly released under a BSD license in July 2005.
