Process of Displaying a Static Page

  1. The Request: A user types a URL or clicks a link, sending an HTTP request to the server.
  2. The URL Router: Django inspects the URL match pattern and maps it to a specific Python view function.
  3. The View: The view intercepts the request, processes any logic, and points to the simple HTML template file.
  4. The Response: Django reads the template file, converts it into a static HTML string, and returns it as an HTTP response to the user's browser.
